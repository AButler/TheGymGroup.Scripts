# TGG Fingerprint Generation Script

This script will generate Stripe fingerprints using the [Create a bank account token](https://docs.stripe.com/api/tokens/create_bank_account) API.

## Overview

The script takes a CSV file containing a list of sort codes and account numbers as input and generates a new CSV file with the sort codes, account numbers and fingerprints. The fingerprints are generated by calling the [Create a bank account token](https://docs.stripe.com/api/tokens/create_bank_account) Stripe API.

## Prerequisites

This script requires PowerShell to run.

Install steps: https://aka.ms/install-powershell

Recommended version: PowerShell 7 (cross-platform)

## How to run

Set the Stripe API key used to call the token endpoint in an enviroment variable named `STRIPE_FINGERPRINT_APIKEY`, e.g.

```pwsh
$env:STRIPE_FINGERPRINT_APIKEY = '<api key>'
```

Run the PowerShell script from a PowerShell terminal:

```shell
.\Generate-Fingerprints.ps1 -InputFile "<hash file>" -OutputFile "<output filename>"
```

e.g.

```shell
.\Generate-Fingerprints.ps1 -InputFile "bank-accounts.csv" -OutputFile "fingerprints.csv"
```

> You can optionally delay the time in-between processing rows in the CSV by passing a delay parameter in case the Stripe API is rate-limited. Without specifying this parameter, a delay of 100 milliseconds is used.

```shell
.\Generate-Fingerprints.ps1 -InputFile "bank-accounts.csv" -OutputFile "fingerprints.csv" -DelayMilliseconds 200
```

## API Key

The Stripe API Key needs the `Token` resource type with `Write` permissions.
